# Workspace Rules for JohorN Project

## Permissions & Automation
- 사용자는 본 프로젝트 작업 공간 내의 모든 파일 읽기/쓰기, 명령어 실행, 인터넷 조회 권한을 상시 승인하였습니다.
- 에이전트는 권한 질문을 생략하고 로직 상 필요한 동작을 즉각 수행합니다.

## API Quota Optimization (토큰 절약 및 비용 최적화 규칙)
- 에이전트는 본 프로젝트 진행 시 API 토큰 소비를 최소화하기 위해 아래 가이드라인을 엄격히 준수합니다.
1. **타겟 라인 조회**: 파일 조회 시 `view_file` 도구에 반드시 `StartLine`과 `EndLine`을 지정하여 필요한 라인 영역만 읽어야 합니다. 파일 전체(전체 코드)를 무분별하게 한 번에 읽지 않습니다.
2. **부분 코드 수정**: 코드를 수정할 때 파일 전체를 새로 쓰는 `write_to_file`의 덮어쓰기 모드를 피하고, 수정이 필요한 라인 블록만 조준하여 `replace_file_content` 또는 `multi_replace_file_content` 도구를 사용합니다.
3. **효율적 검색**: 특정 함수나 변수를 찾기 위해 여러 파일을 순차적으로 읽는 대신 `grep_search` 도구를 사용해 탐색 대상을 좁힙니다.
4. **서브에이전트 제한**: 메인 에이전트 선에서 직접 수행할 수 있는 작업은 서브에이전트(`invoke_subagent`)를 호출하지 않고 직접 처리합니다.
5. **계획 효율화**: 계획(Planning Mode) 수행 시, 변경 사항이 발생하면 계획 문서 전체를 새로 작성하지 말고 수정이 필요한 부분만 부분 수정 도구로 변경합니다.
6. **영어 작성 규칙**: 코드 내 주석(Comments), 로그 메시지(Log messages), 커밋 메시지 등 파일에 기록되는 모든 텍스트 정보는 영어로 작성하여 토큰 사용량을 최소화합니다.
