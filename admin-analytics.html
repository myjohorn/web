Looker Studio 대시보드 1분 연결 안내

URL 등록 대기

구글의 공식 무료 시각화 도구인 Google Looker Studio에서 GA4(G-69ZXT2F4LY) 보고서를 생성한 후 삽입 URL을 등록하시면, 어드민에서 실시간 방문자 차트를 바로 확인하실 수 있습니다.

1

Looker Studio 접속 및 보고서 만들기

lookerstudio.google.com에 로그인한 뒤 [만들기] > [보고서]를 클릭합니다.

2

Google Analytics 데이터 소스 연결

데이터 소스에서 Google Analytics를 선택하고 속성(G-69ZXT2F4LY 또는 조호엔 웹사이트)을 지정하여 보고서를 생성합니다.

3

보고서 삽입(Embed) URL 복사

상단 메뉴의 [파일] > [보고서 삽입]을 누르고 [삽입 사용 설정]을 체크한 후 삽입 URL(https://lookerstudio.google.com/embed/reporting/...)을 복사합니다.

Looker Studio 대시보드 URL 설정

Looker Studio의 [파일] > [보고서 삽입]에서 복사한 삽입 URL을 입력해 주세요. 등록된 URL은 클라우드 DB에 동기화되어 모든 기기에서 공유됩니다.
